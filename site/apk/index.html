설치 순서

티끌은 카드 결제 알림을 읽어 잔돈을 계산합니다. 이런 권한이 있는 앱을 Play 스토어 밖에서 설치하면 Google Play 프로텍트가 설치를 막습니다. 설치하는 동안만 검사를 잠시 꺼 주세요.

  1. 화면 아래 "유해한 파일일 수도 있음" 창에서 "무시하고 다운로드"를 누릅니다. 창 없이 다운로드 알림이 100%에서 멈추면 취소하고 위 버튼을 다시 눌러 주세요.
  2. Play 스토어 → 오른쪽 위 프로필 → Play 프로텍트 → 오른쪽 위 톱니바퀴 → "Play 프로텍트로 앱 검사"를 끕니다. 통화 중에는 끌 수 없습니다. 삼성 휴대폰에서 "자동 차단으로 설치가 차단됨"이 뜨면 설정 → 보안 및 개인정보 보호 → 자동 차단도 잠시 끕니다.
  3. 다운로드 알림이나 내 파일 → 다운로드에서 tikkle.apk를 엽니다. 처음이면 "이 출처 허용"을 켠 뒤 설치합니다.
  4. 설치가 끝나면 2번에서 끈 "Play 프로텍트로 앱 검사"와 자동 차단을 다시 켭니다.
  5. 앱에서 알림 접근을 켤 때 "제한된 설정" 창이 뜨면 설정 → 애플리케이션 → 티끌 → 오른쪽 위 ⋮ → "제한된 설정 허용"을 누른 뒤 다시 켭니다.
