티끌(Tikkle) 개인정보처리방침

티끌(이하 "운영자")는 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 관련 고충을 신속하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다.

제1조 (개인정보의 처리 목적)

운영자는 다음의 목적으로 개인정보를 처리하며, 목적 이외의 용도로는 이용하지 않습니다.

  1. 회원 가입 및 관리 — 가입의사 확인, 본인 식별·인증, 회원자격 유지·관리, 탈퇴 처리
  2. 본인 확인 — 휴대전화 문자메시지를 통한 본인확인
  3. 계정 관리 — 비밀번호 분실 시 본인확인, 계정 보안 관리
  4. 서비스 제공 — 카드 결제 감지, 잔돈 산출, 가상자산 자동 매수 실행, 보유자산 조회
  5. 콘텐츠 제공 — 투자 정보 콘텐츠 제공, 투자성향 기반 매수 종목 추천
  6. 고지사항 전달 — 매수 체결·실패·만료, API 키 오류 등 서비스 중요 정보 통지
  7. 부정이용 방지 — 중복 결제 처리 차단, 등록 카드 외 결제 배제, 인증 남용 방지
  8. 안전 및 보안 — 서비스 안전성 확보, 비인가 접근 차단
  9. 법적 의무 이행 — 관계 법령에 따른 의무 이행 및 분쟁 대응

운영자는 마케팅·광고, 이벤트·프로모션, 인구통계학적 프로파일링 목적으로 개인정보를 처리하지 않습니다.

6. 수집하지 않는 항목

운영자는 다음 정보를 수집하지 않습니다.

  • 실명(성명) — 이용자 표시에는 닉네임만 사용합니다
  • 이메일 주소, 주소, 생년월일, 성별, 국적
  • 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호
  • 계좌번호, 카드번호 전체
  • 「개인정보 보호법」 제23조에 따른 민감정보 (건강·유전·생체정보, 정치적 견해, 종교, 노동조합 가입 여부, 범죄경력, 성생활 정보 등)

제3조 (알림 접근 권한에 관한 특별 고지)

본 서비스는 결제 감지를 위해 Android 알림 접근 권한을 사용합니다. 이용자 보호를 위해 다음 사항을 명확히 고지합니다.

  1. 처리 대상 앱을 제한합니다. 케이뱅크 앱(com.kbankwith.smartbank)의 알림만 처리하며, 그 외 모든 앱의 알림은 읽거나 저장하지 않고 즉시 폐기합니다.

  2. 카드 결제 알림만 처리합니다. 계좌 출금·이체 알림, 승인취소 알림은 처리 대상에서 제외됩니다.

  3. 알림 원문을 저장하지 않습니다. 제2조 제3항의 항목만 추출하며, 알림 전문(全文)은 서버로 전송하거나 저장하지 않습니다.

  4. 전송 구간을 보호합니다. 추출된 정보는 HTTPS 및 HMAC-SHA256 서명을 적용하여 전송합니다.

  5. 권한은 언제든 철회할 수 있습니다. Android 설정 > 알림 접근 권한에서 해제할 수 있으며, 해제 시 결제 감지 기능이 중단됩니다. 앱 내 설정에서 자동 투자 기능을 끄는 것으로도 알림 처리를 중단할 수 있습니다.

제4조 (업비트 Open API 키의 처리)

업비트 API 키는 이용자의 가상자산 거래를 실행할 수 있는 민감한 인증정보이므로 다음과 같이 별도로 관리합니다.

  1. 수집 목적 — 이용자를 대신한 매수 주문 실행 및 보유자산 조회
  2. 보관 방법 — 업비트 Access Key 및 Secret Key는 평문으로 저장되지 않으며, 다음과 같이 암호화하여 서버 DB에 보관합니다.
    • 암호화 방식: AES-256(CBC 모드, PKCS5Padding)을 이용한 양방향 암호화
    • 저장 위치: 당사가 운영하는 서버의 데이터베이스(연동계좌 정보 테이블) 내
    • 암호화 상세: 값을 저장할 때마다 매번 임의의 초기화 벡터(IV)를 새로 생성하여 암호문 앞에 결합한 뒤 인코딩하여 저장하므로, 동일한 키를 여러 번 저장해도 매번 다른 암호문이 생성됩니다.
    • 복호화 키 관리: 암·복호화에 사용되는 비밀키는 소스코드에 포함되지 않고 운영 서버의 비공개 환경설정으로 별도 관리되며, 서비스 운영 목적(매수 주문 실행, 보유자산 조회) 외에는 조회되지 않습니다.
    • 전송 구간 보호: 이용자가 API 키를 등록·변경할 때 앱과 서버 간 통신 구간은 HTTPS(TLS)로 암호화되어 전송됩니다.
  3. 이용자 권장사항 — 업비트에서 API 키 발급 시 출금 권한을 제외하고 발급하실 것을 강력히 권장합니다.
  4. 삭제 방법 — 앱 내 설정 화면에서 언제든 변경·삭제할 수 있으며, 회원 탈퇴 시 즉시 파기됩니다.

제5조 (개인정보의 처리 및 보유 기간)

  1. 운영자는 개인정보 수집·이용 목적이 달성되면 지체 없이 파기합니다.
  2. 회원 탈퇴 시 보유 정보는 즉시 파기합니다.

제6조 (개인정보의 제3자 제공)

운영자는 정보주체의 동의, 법률의 특별한 규정 등 「개인정보 보호법」 제17조 및 제18조에 해당하는 경우에만 개인정보를 제3자에게 제공합니다.

제공받는 자 제공 항목 제공 목적 보유·이용 기간
두나무 주식회사 (업비트) 업비트 API 키, 주문 정보 가상자산 매수 주문 실행 서비스 이용 기간

제8조 (개인정보의 파기)

  1. 파기 절차 — 보유기간 경과 또는 처리목적 달성 시 지체 없이 파기합니다.
  2. 파기 방법
    • 전자적 파일: 복구·재생이 불가능한 방법으로 영구 삭제
    • 출력물: 분쇄 또는 소각

제9조 (정보주체의 권리·의무 및 행사방법)

  1. 정보주체는 언제든지 다음 권리를 행사할 수 있습니다.

    • 개인정보 열람 요구
    • 오류 등이 있을 경우 정정 요구
    • 삭제 요구
    • 처리정지 요구

  2. 앱 내에서 직접 행사할 수 있는 사항

권리 행사 방법
등록 카드 정보 변경 설정 > 카드 정보 변경
업비트 API 키 변경·삭제 설정 > API 키 관리
잔돈 규칙·투자성향 변경 설정 화면
자동 투자 중단 설정 > 투자 기능 On/Off
알림 수신 거부 기기 알림 설정
회원 탈퇴 (전체 삭제) 설정 > 회원 탈퇴
  1. 그 밖의 권리 행사는 제11조의 개인정보 보호책임자에게 요청할 수 있으며, 운영자는 지체 없이 조치합니다.

제10조 (개인정보의 안전성 확보조치)

운영자는 다음과 같은 조치를 취하고 있습니다.

  1. 관리적 조치 — 개인정보 취급자 최소화 및 교육
  2. 기술적 조치
    • 비밀번호 암호화 저장
    • 업비트 API 키 암호화 보관 — 제4조 참조
    • 통신 구간 HTTPS 암호화
    • 결제 정보 전송 시 HMAC-SHA256 서명 검증
    • 인증 토큰 기반 접근통제

제11조 (개인정보 보호책임자)

운영자는 개인정보 처리에 관한 업무를 총괄하여 책임지고, 정보주체의 불만처리 및 피해구제를 위하여 아래와 같이 개인정보 보호책임자를 지정합니다.

제12조 (만 14세 미만 아동의 개인정보 처리)

본 서비스는 만 14세 미만 아동의 회원가입을 제한합니다.

회원가입 시 이용자로부터 만 14세 이상임을 확인받으며, 이에 동의하지 않는 경우 가입 절차가 진행되지 않습니다.
